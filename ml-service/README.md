# EduLens ML Service

This directory contains the Python-based Machine Learning service for EduLens. It handles AI tasks like text summarization, quiz generation, and student performance prediction.

## 📂 Files

- **app.py**: The main entry point for the API. It combines all ML features into a single Flask application.
- **performance_predictor.py**: Script to train the Machine Learning model.
- **performance_model.pkl**: The trained model file (generated by `performance_predictor.py`).
- **requirements.txt**: List of Python dependencies.

## 🚀 Getting Started

1.  **Install Python**: Make sure you have Python installed (version 3.8+).

2.  **Install Dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the Service**:
    ```bash
    python app.py
    ```
    The service will start on `http://localhost:5000`.

## 🤖 Features

- **Text Summarization**: Upload a PDF or extract text to get a summary.
- **Quiz Generation**: Generate MCQs from study material.
- **Study Buddy**: AI Chatbot helper.
- **Performance Prediction**: Predict student pass/fail based on grades.

## ⚠️ Notes

- The API Keys for OpenAI are currently hardcoded in `app.py`. For production, you should move them to environment variables.
- If you see `summerizer&quiz.py` or `route-ml.py`, you can ignore them. We have merged their functionality into `app.py` for simplicity.
